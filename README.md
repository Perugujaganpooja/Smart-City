# 🏙️ Smart City Website

A modern and responsive **Smart City Website** developed using **HTML, CSS, and JavaScript**. This project demonstrates an interactive navigation menu, attractive UI design, hover effects, and informative sections related to smart-city concepts.

## ✨ Features

* 📱 Responsive and user-friendly design
* 🧭 Interactive navigation menu
* ✨ Hover and scroll effects
* 🏠 Home section
* 👥 About Us section
* 🌆 Smart City services and features
* 📞 Contact section
* 🎨 Modern and attractive UI

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality

## 📂 Project Structure

```text
Smart-City/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. You can also run it using **Live Server** in Visual Studio Code.

## 🎯 Project Objective

The main objective of this project is to create an attractive and interactive website that presents the concept of a **Smart City** while demonstrating fundamental front-end web development skills.
